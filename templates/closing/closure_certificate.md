## Closure Checklist

### Deliverables
- [ ] All contracted deliverables have been completed and accepted
- [ ] Customer sign-off obtained on all deliverables
- [ ] Deliverables formally transferred to operations/support

### Financial
- [ ] Final invoices submitted and paid
- [ ] All vendor contracts closed
- [ ] Remaining budget returned to organization
- [ ] Final cost report submitted to Finance

### Documentation
- [ ] All project documents archived per records policy
- [ ] Lessons Learned registered in OPA repository
- [ ] Final Project Report approved
- [ ] Risk register closed and archived

### Resources
- [ ] All team members formally released
- [ ] Performance assessments completed
- [ ] Equipment and assets returned

### Procurement
- [ ] All vendor contracts formally closed
- [ ] Final deliveries accepted
- [ ] Performance evaluations filed

### Stakeholders
- [ ] Formal closure communicated to all stakeholders
- [ ] Stakeholder satisfaction survey conducted
- [ ] Sponsor formally accepts project closure

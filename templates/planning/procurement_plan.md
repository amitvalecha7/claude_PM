**Contract Types:**
- **Fixed Price (FP):** Seller bears cost risk; best when scope is well-defined
- **Time & Material (T&M):** Buyer bears cost risk; best for undefined scope/staff aug
- **Cost-Reimbursable (CR/CPFF/CPIF):** Buyer reimburses costs; best for R&D

## Procurement Process

1. **Plan** — Define requirements, contract type, evaluation criteria
2. **Solicit** — Issue RFP/RFQ/IFB; run bidder conference
3. **Select** — Evaluate proposals using weighted scoring; negotiate; award
4. **Administer** — Monitor performance; manage changes; process payments
5. **Close** — Verify all work complete; close contracts; capture lessons learned

## Escalation Communication Path

```
Team Member → Project Manager (1st contact, resolve within 24h)
    ↓ (if unresolved > 2 days or High impact)
Project Manager → Sponsor / Steering Committee
    ↓ (if unresolved > 3 days or Critical impact)
Sponsor → Executive Leadership
```

---

## Communication Standards

- **Status Report RAG:** Red (off-track, action required) · Amber (at risk, monitoring) · Green (on track)
- **Response SLA:** PM responds to team within 4 hours; Sponsor responds to PM within 24 hours
- **Distribution List:** Maintained in project PMIS; PM owns updates
- **Document Version Control:** All documents versioned; latest version in shared repository
- **Confidentiality:** Financial data and risk details shared only with authorized stakeholders

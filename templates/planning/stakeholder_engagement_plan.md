| Step | Action | Status |
|---|---|---|
| 1. Create Urgency | Communicate the "why now" | |
| 2. Build Guiding Coalition | Engage champions and influencers | |
| 3. Form Vision & Strategy | Co-create the future state | |
| 4. Communicate the Vision | Consistent messaging across channels | |
| 5. Remove Obstacles | Address blockers and resistance | |
| 6. Create Short-term Wins | Deliver quick wins; celebrate milestones | |
| 7. Build on Change | Sustain momentum; don't declare victory early | |
| 8. Anchor in Culture | Embed change in processes and norms | |

## Quality Objectives

| Objective | Metric | Target | Measurement Method |
|---|---|---|---|
| Deliverable Accuracy | Defect rate | < 2 defects per deliverable | Inspection / Review |
| Customer Satisfaction | CSAT score | ≥ 4.0 / 5.0 | Survey |
| Schedule Adherence | % milestones on time | ≥ 90% | Schedule tracking |
| Budget Adherence | CPI | ≥ 0.95 | EVM |
| Test Pass Rate | % test cases passing | ≥ 98% | Test reports |
| Rework Rate | % rework hours / total hours | < 5% | Timesheet tracking |

## Quality Assurance Activities

| Activity | Purpose | Frequency | Owner | Output |
|---|---|---|---|---|
| Process Audit | Verify processes followed | Monthly | PM/QA | Audit Report |
| Peer Review | Review deliverables before submission | Per deliverable | Team | Review Checklist |
| Lessons Learned Review | Improve process continuously | End of phase | PM | Process Update |
| Quality Metrics Review | Track quality KPIs | Weekly | PM | Quality Dashboard |

---

## Quality Control Activities

| Activity | Purpose | Frequency | Owner | Tools |
|---|---|---|---|---|
| Deliverable Inspection | Verify output meets acceptance criteria | Per deliverable | QA | Checklist |
| Testing (UAT, SIT, Unit) | Validate functionality | Per build | QA / Dev | Test Plans |
| Control Charts | Monitor process stability | Ongoing | QA | Control Chart |
| Defect Tracking | Log and resolve defects | Ongoing | Dev / QA | Defect Log |

---

## Defect Management

| Priority | Definition | Resolution SLA |
|---|---|---|
| **Critical (P1)** | System unusable; blocks all users | 4 hours |
| **High (P2)** | Major function broken; workaround unavailable | 24 hours |
| **Medium (P3)** | Function degraded; workaround available | 3 business days |
| **Low (P4)** | Minor issue; cosmetic | Next sprint / release |

---

## Quality Tools & Techniques

| Tool | When Applied |
|---|---|
| Checklists | Deliverable acceptance, phase gate reviews |
| Pareto Analysis | Identifying top defect causes |
| Control Charts | Monitoring schedule/cost/quality stability |
| Root Cause Analysis (Fishbone) | Investigating quality issues |
| Statistical Sampling | Large deliverable sets |
| Process Flow Diagrams | Documenting and improving processes |

---

## Acceptance Criteria Framework

Every deliverable must define acceptance criteria using:
> **Given** [precondition] **When** [action] **Then** [expected result]

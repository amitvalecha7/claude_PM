## Earned Value Management Dashboard

| EVM Metric | Formula | Value | Interpretation |
|---|---|---|---|
| **Budget at Completion (BAC)** | Approved Budget | $ | Total authorized budget |
| **Planned Value (PV)** | % Planned × BAC | $ | What we planned to spend by now |
| **Earned Value (EV)** | % Complete × BAC | $ | Value of work actually done |
| **Actual Cost (AC)** | Actual spend to date | $ | What we actually spent |
| **Schedule Variance (SV)** | EV − PV | $ | (+) ahead / (−) behind schedule |
| **Cost Variance (CV)** | EV − AC | $ | (+) under / (−) over budget |
| **Schedule Performance Index (SPI)** | EV / PV | | >1.0 ahead; <1.0 behind |
| **Cost Performance Index (CPI)** | EV / AC | | >1.0 under; <1.0 over budget |
| **Estimate at Completion (EAC)** | BAC / CPI | $ | Forecast final cost |
| **Estimate to Complete (ETC)** | EAC − AC | $ | Remaining cost forecast |
| **Variance at Completion (VAC)** | BAC − EAC | $ | (+) savings / (−) overrun |
| **To-Complete Performance Index (TCPI)** | (BAC−EV)/(BAC−AC) | | Efficiency needed to meet BAC |
